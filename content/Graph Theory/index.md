# Graph Theory

This index is meant to show the flow of ideas across the graph theory notes.

## Main Threads

- [[Degree Sequences - Havel Hakimi]] -> [[L03-04 - Walks Paths Connectivity]] -> [[L05-06]]: from realizability and basic graph structure into walks, connectivity, and matrix representations.
- [[L05-06]] -> [[L07]] -> [[L08]] -> [[L09]]: the tree thread, moving from structure to spanning trees, Kruskal's algorithm, and counting trees.
- [[L10]] -> [[L11]] -> [[L12]] -> [[L13]] -> [[L14]]: a second thread around reconstruction, connectivity, Menger's theorem, and cycle consequences.
- [[L15]] -> [[L16]] -> [[L17]]: traversability leads into Hamiltonian conditions and closure arguments.
- [[chap9/index|Chapter 9]] -> [[chap9/L18|L18]] -> [[chap9/L19|L19]]: planar graph bounds develop into discharging-style arguments.
