# Lecture Notes: Graph Connectivity

## 1. Definitions & Preliminaries

### **Key Concepts**
* **$\kappa(G)$ (Kappa):** Vertex connectivity. The minimum number of vertices whose deletion leaves $G$ disconnected or trivial.
* **$\lambda(G)$ (Lambda):** Edge connectivity. The minimum number of edges whose deletion disconnects $G$.
* **$\delta(G)$ (Delta):** The minimum degree of the graph.

### **Theorem 5.13 (approximate)**
If $G$ is a graph on $n$ vertices with $m$ edges:
$$
\kappa(G) \le \lfloor \frac{2m}{n} \rfloor
$$

**Proof Idea:**
The sum of degrees is twice the number of edges: $\sum d(v) = 2m$.
The average degree is $\frac{2m}{n}$. Since the minimum degree $\delta(G)$ must be less than or equal to the average degree:
$$
\kappa(G) \le \lambda(G) \le \delta(G) \le \lfloor \frac{2m}{n} \rfloor
$$

## 2. Theorem 5.11: Connectivity Inequality

### **Statement**
For every graph $G$:
$$
\kappa(G) \le \lambda(G) \le \delta(G)
$$

### **Proof**

**Part 1: $\lambda(G) \le \delta(G)$**
* This is trivial. If you remove all edges incident to a vertex with minimum degree $\delta(G)$, the vertex becomes isolated, disconnecting the graph.
* Therefore, the minimum edge cut cannot be larger than $\delta(G)$.

**Part 2: $\kappa(G) \le \lambda(G)$**
* **Case 1 (Trivial):** If $G$ is disconnected or trivial, $\kappa(G) = \lambda(G) = 0$.
* **Case 2 (Complete Graph):** If $G = K_n$, $\kappa(G) = \lambda(G) = n-1$.
* **Case 3 (General):** Suppose $G$ is connected, $|G| = n \ge 3$, and $G$ is not complete.
    1.  Let $X$ be a minimum edge-cut of $G$ such that $|X| = \lambda(G)$.
    2.  Let $G - X$ consist of subgraphs $G_1$ and $G_2$.
    3.  **Observation:** $G_1$ is not complete to $G_2$ (meaning not every vertex in $G_1$ is connected to every vertex in $G_2$). If they were, $|X| \ge n-1$, which contradicts $\lambda(G) \le \delta(G) \le n-2$.
    4.  Therefore, there exist vertices $u \in V(G_1)$ and $v \in V(G_2)$ such that $uv \notin E(G)$.

    **Constructing a Vertex Cut $W$:**
    We build a set of vertices $W$ to cover the edge cut $X$ as follows:
    * For every edge $e \in X$:
        * If $u$ is incident to $e$, add the *other* endpoint of $e$ to $W$.
        * If $u$ is not incident to $e$, add the endpoint of $e$ located in $G_1$ to $W$.

    **Conclusion:**
    * Every edge in $X$ contributes at most 1 vertex to $W$, so $|W| \le |X|$.
    * By construction, $u \notin W$ and $v \notin W$.
    * Since $W$ covers all edges in $X$, removing $W$ destroys all paths between $u$ and $v$.
    * Thus, $W$ is a vertex cut separating $u$ and $v$.
    $$
    \kappa(G) \le |W| \le |X| = \lambda(G)
    $$

## 3. Theorem 5.12: Cubic Graphs

### **Statement**
If $G$ is a **cubic graph** (3-regular, meaning every vertex has degree 3), then:
$$
\kappa(G) = \lambda(G)
$$

### **Proof (by Cases)**
Since $G$ is cubic, $\delta(G) = 3$. We know $\kappa(G) \le \lambda(G) \le 3$. We examine the possible values for $\kappa(G)$.

* **Case 1: $\kappa(G) = 0$**
    * $G$ is trivial or disconnected.
    * $\lambda(G) = 0$. Equality holds.

* **Case 2: $\kappa(G) = 3$**
    * We know $3 = \kappa(G) \le \lambda(G) \le \delta(G) = 3$.
    * Therefore, $\lambda(G) = 3$. Equality holds.

* **Case 3: $\kappa(G) = 1$**
    * Let $\{v\}$ be a cut vertex.
    * Removing $v$ disconnects $G$. Since $d(v)=3$, $v$ has neighbors in the components of $G-v$.
    * By the Pigeonhole Principle, $v$ must have exactly 1 neighbor in one of the components (since $3$ edges cannot be split evenly into $2+$ components without a singleton).
    * The edge connecting $v$ to that single neighbor is a **bridge**.
    * A bridge is an edge cut of size 1, so $\lambda(G) = 1$. Equality holds.

* **Case 4: $\kappa(G) = 2$**
    * We need to show $\lambda(G) = 2$.
    * Let $W = \{u, v\}$ be a minimum vertex cut.
    * $G - W$ has components $G_1, G_2$.
    * Both $u$ and $v$ must have neighbors in both $G_1$ and $G_2$ (otherwise $W$ is not minimal).
    * Since $d(u)=3$ and $d(v)=3$, neither vertex can have 2 neighbors in *both* components.
    * This forces the existence of specific edges (e.g., $uu'$ and $vv'$) that form an edge cut of size 2.
    * Therefore, $\lambda(G) \le 2$.
    * Since $\kappa(G) = 2 \le \lambda(G) \le 2$, we have $\lambda(G) = 2$. Equality holds.

### **Example Counter-Example (General Graphs)**
* **The "Bowtie" Graph:** Two triangles meeting at a single vertex.
    * $\kappa(G) = 1$ (cut the middle vertex).
    * $\lambda(G) = 2$ (cut two edges to separate a triangle).
    * This shows $\kappa(G) < \lambda(G)$ is possible for non-cubic graphs.
