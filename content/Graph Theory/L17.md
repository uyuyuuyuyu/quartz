# Graph Theory Notes: Hamiltonian and Planar Graphs

## 1. Graph Closures and Hamiltonian Conditions
* The closure C(G) of a graph G is the graph resulting from iteratively adding edges between nonadjacent vertices with a degree sum >= n.
* If |G| = n >= 3 and C(G) = K_n, then G is Hamiltonian.

### Theorem (Chvátal's Condition)
* Let G be a graph of order n >= 3. 
* If the number of vertices with a degree of at most i is less than i, then G is Hamiltonian.

**Proof (by contrapositive):**
* Let G' be a graph, |G'| = n >= 3, and G' is non-Hamiltonian. 
* Then set G = C(G') and note G is also non-Hamiltonian; in particular, G is not complete. 
* We will show there exists an integer k, 1 <= k < n/2, such that there exists a collection of at least k vertices whose degrees are all at most k in G. 
* Since G != K_n, it has at least one pair of nonadjacent vertices. 
* Choose u, w to be a nonadjacent pair with maximum degree sum, and say d(u) <= d(w). 
* If d(u) = 0, then set k = 1, and {u} is the desired set. 
* Suppose now d(u) >= 1 and set k = d(u). 
* Since u and w are nonadjacent in G, and G is a closure, d(u) + d(w) <= n - 1. 
* Since d(u) <= d(w), d(u) = k <= (n-1)/2. 
* Also from d(u) + d(w) <= n - 1 we see d(w) <= n - 1 - k. 
* Let W = V(G) - N(w). 
* W consists of vertices in G that form a nonadjacent pair with w. 
* By choice of u, for all v in W, d(v) <= d(u) = k. 
* |W| = n - 1 - d(w) >= (n - 1) - (n - 1 - k) = k.
* Then these vertices also have degree <= k in G', as desired.

## 2. The Chvátal-Erdős Theorem (1972)
* Recall that alpha(G) is the independence number, which is the size of the longest independent set.

### Theorem Statement
* Let G be a graph, |G| >= 3. 
* If G is s-connected and alpha(G) <= s, then G is Hamiltonian.

**Proof:**
* Let G, s be as described.
* If s = 1, then G is complete, so G is Hamiltonian. 
* So, suppose s >= 2. 
* Since G is 2-connected, it is not a tree. 
* Let C be a longest cycle in G. 
* By way of contradiction, suppose there exists x in V(G) \ V(C). 
* By Theorem 5.11, kappa(G) <= lambda(G) <= delta(G). 
* Let S be a collection of s vertices in C. 
* By Corollary 5.19, there exists a collection of s paths from x to S intersecting at x. 
* Let x_i be the vertices on these paths in C that are closest to x, and call the x-x_i path P_i. 
* Where x_i are labelled in order around C. 
* Let y_i be the successor of x_i along C. 
* Note if xy_i is in E(G) for any i, then replacing the edge x_iy_i with P_i U xy_i gives a longer cycle than C. 
* Consider the set containing x and y_i. 
* Since alpha(G) <= s, it has an edge. 
* Since x is not the endpoint of any edge in that set, the edge connects y_i and y_j. 
* This forms a cycle strictly longer than C.

## 3. Planar Graphs (Chapter 9.1)
* A graph G is called planar if it can be drawn in the plane with no edges crossing. 
* Otherwise G is nonplanar. 
* A drawing of a graph in the plane is a plane drawing. 
* Planar graphs include paths, cycles, and trees.

### The Utilities Problem
* This problem involves three houses and three utilities: water, elec, and gas.
* It asks if it is impossible to draw K_3,3 in the plane without edges crossing, or if we just chose a bad drawing.
