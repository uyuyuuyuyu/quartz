## 1. Graph Reconstruction (Section 3.4)

### Definitions
*   **The Deck ($D$):** The multiset of all vertex-deleted subgraphs of a graph $G$.
*   **Card:** A single graph in the deck, denoted $G-v$ (the graph obtained by deleting vertex $v$ and all incident edges).
*   **Recognizable:** A property is recognizable if it can be determined from the deck.
*   **Reconstructible:** A graph $G$ is reconstructible if the graph itself is determined by the deck (up to isomorphism).

### Theorems on Recognizability

**Theorem 3.11: The order of every graph is recognizable.**
*   **Proof:** Count the number of cards in the deck. If $|D| = n$, then $|V(G)| = n$.

**Theorem 3.12 (Kelly's Lemma): The size of every graph (for $n > 2$) is recognizable.**
*   **Formula:** Let $||G||$ be the number of edges (size) of $G$.
    $$ ||G|| = \frac{\sum_{v \in V(G)} ||G-v||}{n-2} $$
*   **Proof Logic:**
    1.  Consider any edge $e \in E(G)$.
    2.  This edge $e$ appears in a card $G-v$ if and only if $v$ is **not** an endpoint of $e$.
    3.  Since $e$ has exactly 2 endpoints, it appears in exactly $(n-2)$ cards.
    4.  Summing the edges on all cards counts every edge of $G$ exactly $(n-2)$ times.

**Theorem 3.13: The degree sequence is recognizable.**
*   **Formula:** For any card $G-v$, the degree of the deleted vertex $v$ is:
    $$ d(v) = ||G|| - ||G-v|| $$

**Theorem 3.14: Connectedness is recognizable.**
*   **Theorem:** A graph of order $\geq 3$ is connected if and only if there exist at least two distinct vertices whose removal does not disconnect the graph.
*   **Application:** By checking if at least two cards in the deck are connected graphs, we determine if $G$ is connected.

### Reconstruction of Disconnected Graphs

**Theorem (Kelly, 1957): Disconnected graphs of order $\geq 3$ are reconstructible.**
*   **Proof:**
    1.  Since connectedness is recognizable, assume we know $G$ is disconnected.
    2.  Let $D$ be the deck.
    3.  Let $K$ be a component of maximum order found among all cards in $D$.
    4.  **Claim:** $K$ is a component of $G$.
        *   *Reasoning:* Let $J$ be a component of $G$ of maximum order.
        *   Removing a vertex from $G$ might reduce the size of $J$ or break it, but it cannot create a component larger than $J$.
        *   Thus, the largest component found in the deck must be isomorphic to $J$.
    5.  By identifying these maximal components, we can reconstruct $G$ uniquely.

**Reconstruction Example (Board 13):**
*   If we know $G$ is disconnected:
    *   Let $M$ be the maximum component found in the deck.
    *   Let $L$ be the second largest component.
    *   Identify a card where the component $M$ was modified (e.g., a vertex was lost from it).
    *   By comparing cards containing $M$ vs cards containing $M-v$, the structure is fixed.

## 2. Regular Graph Embeddings (Theorem 2.7)

**Theorem 2.7:** For every graph $G$ and every integer $r \geq \Delta(G)$ (max degree), there exists an $r$-regular graph containing $G$ as an induced subgraph.

*   **Proof (The Construction Algorithm):**
    1.  Start with graph $G$.
    2.  If $G$ is already $r$-regular, we are done.
    3.  If not, create a disjoint copy of $G$, call it $G'$.
        *   $V(G') = \{v'_1, \dots, v'_n\}$
        *   $E(G') = \{v'_i v'_j : v_i v_j \in E(G)\}$
    4.  Construct a new graph $G_1$ with vertex set $V(G) \cup V(G')$.
    5.  **Edge Construction:**
        $$ E(G_1) = E(G) \cup E(G') \cup \{ v_i v'_i : d_G(v_i) < r \} $$
    6.  This adds an edge between a vertex and its copy **only if** the degree is currently too small.
    7.  This increases the minimum degree $\delta$. Repeat this process iteratively until the graph becomes $r$-regular.

## 3. Connectivity (Chapter 5)

### Structural Definitions
*   **Cut Vertex:** A vertex $v$ is a cut vertex if $G-v$ has more connected components than $G$.
*   **Bridge:** An edge $uv$ is a bridge if $G-uv$ has more connected components than $G$.

### Theorems on Cut Vertices

**Theorem 5.1:** Let $v$ be an endpoint of a bridge $uv$ in a graph $G$. Then $v$ is a cut vertex if and only if $d(v) \geq 2$.
*   **Proof:**
    *   **($\Leftarrow$):** Assume $d(v) \geq 2$. $v$ has neighbors other than $u$. Removing the bridge $uv$ puts $u$ in a different component than $v$. Removing $v$ destroys the path from $v$'s other neighbors to $u$, disconnecting the graph.
    *   **($\Rightarrow$):** If $d(v) = 1$, $v$ is a leaf. $G-v$ is connected (if $G$ was). Thus $v$ is not a cut vertex.

**Theorem 5.3:** Let $v$ be a vertex in a connected graph $G$. If $v$ separates two vertices $x$ and $y$, then $v$ lies on every path between $x$ and $y$.

**Corollary 5.4:** A vertex $v$ is a cut vertex iff there exist $x, y \in V(G)$ such that $v$ lies on every $x-y$ path.

**Theorem 5.5 (Diameter Argument):** Let $G$ be a connected graph. Let $v$ be a vertex of maximum distance from some vertex $x$ (i.e., an endpoint of a diametral path). Then $v$ is **not** a cut vertex.
*   **Proof (By Contradiction):**
    1.  Assume BWOC that $v$ is a cut vertex.
    2.  Then $G-v$ is disconnected. Let $x$ be in one component and $w$ (a neighbor of $v$) be in another.
    3.  Every path from $x$ to $w$ must pass through $v$.
    4.  Distance: $d(x,w) = d(x,v) + d(v,w) = d(x,v) + 1$.
    5.  So $d(x,w) > d(x,v)$.
    6.  Contradiction: We chose $v$ such that $d(x,v)$ was the maximum distance in $G$.
    7.  Therefore, $v$ is not a cut vertex.

**Corollary 5.6:** Every nontrivial connected graph contains at least two vertices that are not cut vertices (the two ends of a diameter).

### Minimal Vertex Cuts (Observation from )

**Definition:** A **Minimum Vertex Cut** is a vertex cut with minimum cardinality.

**Observation:** Suppose $U$ is a minimum vertex cut of a connected graph $G$. Let $G-U$ have components $G_1, \dots, G_k$. Then **every vertex $u \in U$ has a neighbor in every component $G_i$.**
*   **Proof:**
    1.  Suppose there is a vertex $u \in U$ that does **not** have a neighbor in some component $G_j$.
    2.  Then removing $u$ from the cut set $U$ (forming $U' = U \setminus \{u\}$) would still leave $G_j$ disconnected from the other components.
    3.  This implies $U'$ is also a vertex cut.
    4.  Since $|U'| < |U|$, this contradicts the assumption that $U$ was a *minimum* vertex cut.

### Connectivity Measures & Menger's Concept

**Definitions:**
*   **Vertex Connectivity ($\kappa(G)$):** Min size of a vertex cut.
*   **Edge Connectivity ($\lambda(G)$):** Min size of an edge cut.
*   **$u-v$ Separating Set:** A set $S$ separates $u$ and $v$ if they are in different components of $G-S$.
*   **Notation:** $\kappa(u,v)$ is the size of the smallest set separating $u$ and $v$.

**Whitney's Inequality ():**
For any graph $G$:
$$ \kappa(G) \leq \lambda(G) \leq \delta(G) $$
*(Vertex connectivity $\leq$ Edge connectivity $\leq$ Minimum degree)*

**Examples:**
*   **Complete Graph ($K_n$):** $\kappa(K_n) = n-1$. (Has no vertex cut, requires removing $n-1$ vertices to leave a trivial graph).
*   **Path ($P_n$):** $\kappa(P_n) = 1$.
*   **Cycle ($C_n$):** $\kappa(C_n) = 2$.
*   **Complete Bipartite ($K_{n,m}$):** $\kappa(K_{n,m}) = \min(n, m)$.
*   **$K_{3,3}$:** Is 1-connected, 2-connected, and 3-connected. $\kappa(K_{3,3}) = 3$.
