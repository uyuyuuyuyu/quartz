# §5.4 Menger's Theorem


---

## I. Definitions
* **Internally Disjoint Paths:** Two paths are "internally disjoint" if they share no internal vertices and no edges .
* **Separating Set Size ($\kappa(u,v)$):** For distinct, nonadjacent vertices $u,v$ in a graph $G$, we write $\kappa(u,v)$ for the minimum size of a $u-v$ separating set .
* **Path Count ($\lambda(u,v)$):** We write $\lambda(u,v)$ for the maximum cardinality of a set of pairwise internally disjoint $u-v$ paths .

---

## II. Preliminary Results

### Observation
Let $W$ be a minimum $u-v$ separating set in $G$, with $w \in W$. Then $W \setminus \{w\}$ is a minimum $u-v$ separating set in $G-w$ .

* **Proof:**
    * Note that $(G-w) - (W \setminus \{w\}) = G-W$, so $W \setminus \{w\}$ is indeed a $u-v$ separating set in $G-w$ .
    * **Minimality:** Suppose there exists a smaller separating set $W'$ in $G-w$ such that $|W'| < |W|-1$. Then $W' \cup \{w\}$ would be a separating set in $G$ with size $< |W|$, which contradicts the minimality of $W$ .

### Lemma 
Let $W$ be a minimum $u-v$ separating set in $G$. For any $w \in W$, $G$ contains a $u-w$ path with no internal vertices from $W$ .

* **Proof:**
    * By the minimality of $W$, the set $W \setminus \{w\}$ does not separate $u$ and $v$ .
    * Therefore, there exists a $u-v$ path in $G - (W \setminus \{w\})$ .
    * Since there is *no* $u-v$ path in $G-W$ (as $W$ is a separator), this path must contain $w$ as an internal vertex. Deleting the portion of the path from $w$ to $v$ gives the desired $u-w$ path .

---

## III. Theorem 5.16 (Menger's Theorem)

**Statement:** Let $u,v$ be nonadjacent vertices in a graph $G$. The minimum number of vertices in a $u-v$ separating set is equal to the maximum number of pairwise internally disjoint $u-v$ paths .

$$\kappa(u,v) = \lambda(u,v)$$ 

### Proof

**Direction 1: $\kappa(u,v) \ge \lambda(u,v)$**
If we delete fewer than $\lambda(u,v)$ vertices from $G$, then at least one of the $\lambda(u,v)$ paths remains intact. Thus, any separating set must have size at least $\lambda(u,v)$ .

**Direction 2: $\kappa(u,v) \le \lambda(u,v)$**
We show this by induction on the number of edges, $||G||$ . Let $k = \kappa(u,v)$.

1.  **Base Case:** If $u,v$ are connected but nonadjacent with minimal edges (or if $||G||$ is small), $u$ and $v$ are in a component isomorphic to a simple structure where the theorem holds (e.g., $k=0$ or $k=1$) .
2.  **Inductive Step:** Assume the theorem holds for every graph with fewer edges than $G$ . We assume $k \ge 2$ .

    **Case 1:** There exists a minimum separating set $W$ and a vertex $x \in W$ such that $x \in N(u) \cap N(v)$ (x is a neighbor to both) .
    * Consider $G-x$. Then $W \setminus \{x\}$ is a minimum separating set in $G-x$ of size $k-1$ .
    * By the Inductive Hypothesis (IH), $G-x$ has a collection of $k-1$ internally disjoint paths .
    * Adding the path $u-x-v$ (which is internally disjoint from the others) gives $k$ paths .

    **Case 2:** The vertices in $W$ are not all common neighbors. Specifically, the paths from $u$ to $W$ are not just single edges .
    * **Construction:**
        * Let $G_u$ be the subgraph of $G$ consisting of all paths from $u$ to $W$ with no internal vertices from $W$ .
        * Create $G'_u$ by adding a new vertex $v'$ to $G_u$ and adding edges from all $w \in W$ to $v'$ .
    * **Edge Count (Crucial Step):**
        * By the Lemma, every $w \in W$ has a path to $v$ in the original $G$ (avoiding $W$ internals). At least one of these paths had length $\ge 2$ edges (otherwise we would be in Case 1) .
        * In $G'_u$, these paths are replaced by single edges.
        * Therefore: $||G'_u|| = ||G_u|| + k < ||G||$ .
    * **Separating Set:**
        * $W$ is a minimum $u-v'$ separating set in $G'_u$ . If there were a smaller set $W'$, it would also separate $u,v$ in $G$, contradicting $\kappa(u,v)=k$ .
    * **Conclusion:**
        * By IH, there are $k$ internally disjoint paths in $G'_u$ . Similarly for $G'_v$ .
        * Deleting the dummy vertices and gluing the paths at $W$ gives $k$ internally disjoint $u-v$ paths in $G$ .
