# A=LU

This folder is a connected set of notes around elimination, solvability, and subspaces.

## Elimination Track

- [[matrixNote]] -> [[permutation]] -> [[A=LU]]: matrix multiplication, inverses, and row permutations set up the factorization viewpoint.
- [[A=LU]] -> [[Solving-Ax=b]]: once the matrix is factored, solving systems becomes forward and backward substitution.
- [[Solving-Ax=b]] -> [[Pivot Variables and Special Solutions]]: solvability of `Ax=b` connects directly to pivot structure and the nullspace of `Ax=0`.

## Subspace Track

- [[Column Space and Nullspace]] -> [[fundamental subspaces]]: start with the two main spaces, then place them inside the full four-subspace picture.
- [[Pivot Variables and Special Solutions]] -> [[fundamental subspaces]]: special solutions explain the basis of the nullspace.
- [[fundamental subspaces]] -> [[matrix spaces rank]] -> [[Independence Basis and dimension]]: rank leads into the dimensions and basis language used across the spaces.
