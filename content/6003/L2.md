# 1. Recap: Classical and Modern Cryptography

## 1.1 Kerckhoffs's Principle

Classical cryptographic systems often depended on keeping their encryption methods secret.

Modern cryptography follows Kerckhoffs's principle:

> A cryptographic system should remain secure even when its design and algorithms are publicly known. Only the secret key needs to remain secret.

This allows cryptographic systems to be publicly analyzed for weaknesses.

## 1.2 Cryptographic Security Goals

Cryptography can provide different security properties.

| Goal | Meaning |
|---|---|
| Confidentiality | Prevent unauthorized parties from reading messages. |
| Authenticity | Verify that a message comes from the expected sender. |
| Integrity | Detect unauthorized modifications to data. |

These are distinct security goals.

Encryption that provides confidentiality does not automatically provide authenticity or integrity.

Before selecting a cryptographic algorithm, determine which properties the application requires.

# 2. Shannon's Cipher Model

Claude Shannon formalized a cipher using three sets and three algorithms.

## 2.1 Three Sets

A cipher has:

- Plaintext space $\mathcal{M}$.
- Ciphertext space $\mathcal{C}$.
- Key space $\mathcal{K}$.

## 2.2 Three Algorithms

| Algorithm | Purpose |
|---|---|
| $\operatorname{Gen}$ | Generates a key. |
| $E_K(M)$ | Encrypts plaintext $M$ using key $K$. |
| $D_K(C)$ | Decrypts ciphertext $C$ using key $K$. |

## 2.3 Correctness

A cipher must satisfy:

$$
\boxed{D_K(E_K(M))=M}
$$

Encrypting a message and then decrypting it using the same key must recover the original plaintext.

Correctness does not imply security.
